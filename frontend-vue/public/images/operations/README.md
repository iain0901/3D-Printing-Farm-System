# 智慧工場展示素材

2026-11-07，由 OpenAI 圖片生成工具依本次使用者需求生成，格式轉換為 WebP。不是實際 Creality Hi 照片、相機串流或品管證據。

- `farm-cameras.webp`：2×2 合成機台視角，列印支架／間隔柱、失敗堆料、空機保養。外觀為通用 FDM，不作機型規格證明。
- `inspection-defect.webp`：支架多視角與底部裂縫特寫；幾何與角度並非經過量測／校準。
- `inspection-clean.webp`：良品支架四視角示意；不能當真實良品基準資料集。

每個檔案僅在其對應展示流程使用，畫面保持 AI 示意標籤。原始 PNG 留在生成工作區，部署只需這三張 WebP。不要把這些素材匯入正式品管訓練或維修觀測。
