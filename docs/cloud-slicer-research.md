# 雲端切片工作區研究與實作對照

研究日期：2026-10-23（臺北）。直接閱讀官方文章的完整 SSR 資料、教學影片，並查看介面截圖；沒有登入或操作他人的帳號。

來源：

- https://www.crealitycloud.cn/help-center/67bd83b8f5a52c997c155581 ：App／Web 雲切片操作指南。閱讀選模型、環視、機台／噴嘴／耗材、等比與非等比縮放、旋轉、工藝、保存與切片。
- https://www.crealitycloud.cn/help-center/multi-model-slicing-web ：Web 多模型操作。閱讀單選／Ctrl 多選、軸向移動、三種縮放把手、旋轉、克隆、隱藏、全部重設、自動布局、按面放平及快速視圖。

觀察：Web 工作區讓 3D 平台佔據主要空間；左邊放操作工具與物件清單，右邊集中機型、耗材、製程及可搜尋的參數。切片是固定且明確的主要動作。相機環視與實際改變模型方向分開；選取、超界和模型可見性有狀態回饋。基本設定先呈現層高、填充、支撐，進階設定分成品質、強度、速度、支撐與其他。

3DRFM 採自己的品牌、繁體中文、元件與實作，參考資訊架構和互動原則，不將他們的商標、截圖、影片、產品圖或網站程式碼放入產品。

已實作的對照：

| 操作階段 | 工作區需求 |
| --- | --- |
| 準備模型 | 同一 3D 列印平台、STL 匯入、物件清單、單選／多選、移動／旋轉／等比與非等比縮放、鏡像、複製、隱藏、刪除、重設、復原／重做 |
| 平台與方向 | 建構體積、平台網格與安全邊界、超界提示、自動排版、按面放平、上下左右前後／等角視圖、相機旋轉／平移／縮放 |
| 列印設定 | 機台與噴嘴、耗材、基本／進階／搜尋、層高、線寬、填充圖案與密度、牆圈、頂底層、支撐種類與角度／位置、附著、縫線、速度與回抽；只開放後端確實接受的設定 |

機台、耗材與後端能力必須和畫面一致。沒有設定的機台不以參考機型冒充；沒有接上實際多色切片時，不把模型上色顯示宣稱成已完成多色 G-code。研究文章的「發起列印」不代表授權此工作區直接操作現場設備。

## 入口與操作

- 公開 `/#/cloud-slicer`：獨立試切工作區，官網「技術資源」可進入。無須登入即可匯入 STL、布局、試切片及保存本機 ZIP 專案；登入可讀自己的模型庫、保存雲端草稿，再到代印工作台繼續配色、提交需求。
- `/#/free-print/nthu-shuimu/slicer`：同一工作區，材料固定顯示 `3DSTU_PETG`。完成試切不代表取得免費名額，會員仍須申請並由站點確認。
- `/#/quote`：共用完整三維平台與上色功能，保留會員草稿和專員報價流程；付費新機型切片尚未啟用，不能把獨立參考機台的試切結果當成正式報價。
- 員工 `/#/slicer/index`：使用相同工作區和員工模型庫，不從瀏覽器直接控制印表機。

工具列提供選取 Q、移動 W、旋轉 E、縮放 R、按面放平 F；Ctrl／⌘ 點選多選、Ctrl A 全選、Ctrl D 複製、Ctrl Z／Ctrl Shift Z 復原／重做、Delete 刪除、方向鍵移動 1 mm／Shift 10 mm。數值欄和 Three.js 三維把手都會變更真正上傳的 STL，不只是改變外觀。多選支援共同移動；旋轉／縮放針對單件。隱藏只影響檢視，仍參與切片，畫面明示此行為。

原始 STL 在 worker 處理；旋轉、非等比縮放、鏡像維持面編號，鏡像修正繞向。重建時使用原始檔而非重複變換已烘焙檔。資料量限制仍為五個 STL、合計 10 MiB、每個 20 萬面；模型須貼齊平台，不提供懸浮 Z 放置、網格修復、切割或 3MF／OBJ 匯入。

## 真實運算與資料契約

`POST /api/public/slicing-quotes` 新增 `purpose: studio`，使用既有匿名工作 token 和 Orca worker。此用途沒有價格、不建立案件／付款訂單／生產佇列，亦不能拿此 token 建立付費報價案件。取消與過期結果處理沿用既有工作隔離。

可試切的機台僅經驗證的 Artillery M1 Pro 0.4 mm 參考設定，平台 260 mm 立方；獨立工作區可選已有實際設定檔的 PETG、PLA、ASA、TPU。免費站點固定 PETG。進階設定定義集中在 `slicer-settings.mjs`，後端 strict schema 驗證後轉換為 Orca 製程／機台欄位；未填欄位繼承真實設定檔。沒有其他機型、噴嘴選單假選項。

`GET /api/public/slicing-quotes/:id/toolpaths` 僅接受 `x-slicing-token`，不將 token 放進 URL；只讀目前工作區已完成工作真實 G-code。解析 XYZ、G90／G91、M82／M83、G92、不同工具與回抽，輸出逐層線段、特徵、速度、工具；最多 100000 線段、2000000 行、3000 層／64 MiB 結果。截斷、圓弧不支援或多盤串接均明示，不捏造缺少路徑。參考試切已關閉圓弧輸出。三維預覽可選起訖層、目前層、特徵篩選、線段進度、播放速度，播放不會連線到機器。

本機 ZIP 專案格式 `3drfm.slicer-project.v1`：`project.json` 加原始 `sources/*.stl`，保存方向、布局、可見性及製程設定；不是 Orca 3MF，不含會員 token。允許保存尚未完成布局的工作，但必須完成範圍／間距驗證才能送切片。會員雲端保存沿用 `3drfm.quote-workspace.v2`，原始及烘焙 STL 均有權限保護，revision 避免覆寫衝突；詳見會員工作台文件。

## 驗證紀錄

- `npm test`：36 個檔案、312 項測試通過。新增鏡像繞向／面索引、點面放平、歷史快照、18 項進階設定映射、真實 G-code 解析與 studio API 權限／不建立訂單測試。
- `npm run build`：檢查實際 Rspack 編譯成功與產物，不僅採用命令回傳碼。
- `scripts/check-slicer-studio.cjs`：正式 build／Chromium WebGL，布局、縮放、鏡像、旋轉歷史、多選、複製、隱藏、點面放平、進階參數、ZIP 還原、路徑滑桿播放、320～1440 px。
- `REAL_SLICE=1` 執行同一腳本：本機隔離 API＋實際 OrcaSlicer 2.4.2 worker。三模型含鏡像與非等比縮放、gyroid 與自訂回抽成功切片，再讀取真實 G-code 逐層預覽；不攔截切片 API、不操作設備。
  最終測試得到 180 層、64664 條路徑、10.671 g／42.267 分鐘；逐件核對第二層外壁路徑落在保存的手動位置，確認 CLI 未重新置中布局。這是該測試模型與參考設定的運算結果，不是通用價格或交期承諾。
- `scripts/check-member-workspace.cjs`：真實會員 API，模型庫帶入、非等比／鏡像雲端保存與報價工作台還原，另驗證上色、自動保存、案件與站點取件流程。
- `scripts/check-surface-paint.cjs`：同一平台的筆刷／填色／橡皮擦、復原／重做、幾何綁定、模型切換、觸控、模型刪除後復原配色；未呼叫任何付費切片或設備 API。

正式網站發布與實際新機型／多色運算仍需對應部署管道及新的後端設定；不能將推送 main 描述為已更新線上網站。
