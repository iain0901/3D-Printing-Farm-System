# 3DRFM 共用視覺規格

以首頁現有的海軍藍、鈷藍、暖橘與暖白為品牌基準，不再讓官網、會員、報價和切片各自定義一組青綠色。

## 單一來源

- `frontend-vue/src/styles/brand-tokens.scss`：品牌文字／主操作、互動、裝飾、底色、邊線、輔助文字、字型、控制項／面板圓角、標題尺寸、焦點環。由 `main.js` 載入。
- `components/public/BrandMark.vue`：官網導覽、頁尾、會員側欄與切片標頭共用同一字標。工具列使用 compact 密度，不另畫一套商標。
- `brand-surface`：官網、會員與切片三個外框的主題邊界，包含 Element Plus 主色和表單變數。不把全域後台、材料色槽或 G-code 特徵顏色一律換成品牌色。
- `brand-dialog`：會員、報價及切片彈窗，即使 teleport 離開原外框仍沿用相同字型、主色及圓角。
- PWA 的 theme-color、背景與獨立離線頁同步更新；離線頁內嵌必要規格，不能依賴尚未載入的應用程式 bundle。

## 保留的差異

統一品牌不等於每頁使用同一布局。首頁保留大標題、模型圖片與展示段落；服務／指南共用頁級標題尺度；會員採較緊湊的資料版面；切片保留大平台、工具列及參數側欄。圖片自身的色彩、材料預覽、上色色槽、成功／警告／錯誤仍有各自語意，不以品牌色取代。

首頁不再透過 `:deep` 個別覆寫導覽字標、導覽面板、標頭和頁尾，因此換頁不再改變外框身份。新增頁面應使用現有 shell 與 tokens；除插圖／產品色、資料圖表或狀態外，不新增獨立品牌調色盤。

## 驗證

- `api/brand-consistency.test.mjs`：共用 tokens、三個外框與字標引用、首頁外框覆寫防退化、PWA／離線配色。
- `scripts/check-brand-consistency.cjs`：真實 build 與隔離 API；逐頁核對計算後的字標、主色、背景、導航、頁尾、圓角和字型；登入後明確等待會員外框，不能以登入頁誤當會員頁。涵蓋所有公開服務／資訊頁、會員中心、切片、彈窗與離線頁，並檢查 320／390／768／1440 px 無水平溢出。
- 會員雲端模型／上色保存、案件／取件流程及完整切片工作區的既有瀏覽器回歸維持不變。

本次驗證：正式 build 成功；37 個測試檔案／316 項測試通過；32 個公開路徑與登入後會員／切片頁跨尺寸比對通過。會員功能、模型上色、雲端保存和切片操作瀏覽器回歸均通過，沒有因此執行付款或控制實體設備。

此變更僅涉及呈現，不更動切片參數、會員權限、價格、付款、訂單或資料模型；推送 main 亦不等同完成正式站發布。
