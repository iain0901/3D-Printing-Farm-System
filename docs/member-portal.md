# 3DRFM 會員工作台

會員介面使用 `/portal/dashboard`，與員工後台和公開案件分享連結分開。此改版不更動登入 API、權限、資料結構、價格計算或印表機控制。

## 畫面與導覽

- 桌機固定側欄，手機四項導覽：列印案件、報價與訊息、訂單與配送、收件地址。
- 使用 `?tab=cases|quotes|orders|addresses` 保存所在功能區；重新整理與瀏覽器上一頁可恢復分頁。無效值回到列印案件。
- 概況由會員 API 回傳資料計算，不使用展示數字。載入中或失敗顯示破折號，避免將讀取失敗誤認為零筆資料。
- 待回覆包括案件報價／補件／回覆，以及報價單中的待確認細節；同一報價單多個待確認項目只計一件。
- 案件、報價、訂單與付款狀態使用繁體中文對照；未知代碼顯示「待專員確認」。未提供報價不顯示成零元。
- 保留報價決定、檔案預覽、對話附件、生產確認、物流、再訂購、優惠券、點數與地址管理。未設定完成的付款方式不可提交。
- 有明確的空白、載入、錯誤與重新載入狀態；支援鍵盤焦點、跳至主內容、表單標籤及減少動態效果偏好。

## 驗證

```bash
npm test -- api/portal-presentation.test.mjs
npm run build
BASE_URL=http://127.0.0.1:8799 node scripts/check-member-portal.cjs
```

瀏覽器腳本需 Playwright 與 Chromium，可透過 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH` 指定既有安裝。使用專案既有 API 靜態託管方式啟動隔離測試站，並在重新建置後重啟測試服務，確保新資產已註冊。

腳本僅允許 localhost／127.0.0.1，所有會員資料與寫入使用測試攔截，不可對正式站執行。覆蓋 320、390、768、1024、1440px、四項導覽、資料狀態、報價回覆、訊息、確認、物流、付款選項、編輯地址、登出與失效登入。截圖中的姓名、案件和金額均為測試資料。

正式部署仍需網站主機權限；推送 main 不等於正式站已更新。
