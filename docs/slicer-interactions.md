# 切片互動、進度與功能說明

日期：2026-10-23（臺北）。適用公開雲端切片、水木書苑免費切片、員工切片及共用代印工作台；不變更正式機台、價格或印表機控制。

## 立即朝向與排版

「立即自動朝向」取代等到 Orca 執行才定向的勾選項。按下就透過瀏覽器 worker，把全部模型目前包圍框的最短軸轉成高度、底面落在 Z=0，再依包圍框及間距重新排版。這是快速幾何判斷，不保證最少支撐或最佳製造方向；可用「按面放平」指定底面或手動旋轉。

- 預覽、草稿及上傳使用同一份烘焙 STL。`sourceTransform.layFlat` 留作原始檔重建紀錄，不得再次套用到烘焙 STL。
- 朝向與重排合為一次歷史操作，可一次復原／重做；重複按下結果穩定。單件「自動平躺」只調整選取模型。
- 「立即自動排版」只改位置；超界或放不下會提示，不偽裝為成功。
- 代印已設定高度換色時停用整台自動朝向；手動變換後仍須檢查區間。
- 新切片工作固定 `autoOrient: false`、`autoArrange: false`，保留畫面方向與位置。讀取舊 ZIP／雲端草稿會清除延後定向選項；ZIP 載入顯示遷移提示。API 維持舊客戶端相容。

## 真實進度，不虛構百分比

點「開始切片」立即在主要操作區顯示進度條。

| 階段 | 來源 | 百分比 |
| --- | --- | --- |
| 上傳／建立工作 | Axios 上傳事件；100% 後仍等待伺服器回覆 | 已知總位元組數時顯示真實上傳比例 |
| 排隊 | 伺服器 `queued` | 不定進度，不以計時推算 |
| 切片 | 伺服器 `processing` | 引擎無百分比 API，明示運算中 |
| 讀取路徑 | 工作完成，`/toolpaths` 未完成 | 不定進度，不宣稱整體完成 |
| 路徑就緒 | 取得實際預覽 | 完成 100% |
| 中斷／失敗／取消 | 原工作狀態與錯誤 | 停止跑動，不顯示假的完成百分比 |

使用 `role=progressbar`、繁體中文 `aria-valuetext`；不定進度不設 `aria-valuenow`。標題為禮貌即時區域並尊重減少動態設定。讀取路徑時也鎖定編輯。重整恢復原工作、不重複 POST；查詢與路徑錯誤可重試。取消若遇工作已完成，提示並讀取結果，不停在無限進度。

## 問號說明

`slicer-help.mjs` 集中管理目錄及 18 項進階設定的專屬說明；`SlicerHelp.vue` 不在原按鈕或 label 裡巢狀加入另一按鈕。

- 滑到工具、欄位或展開項目會出現可點問號；不觸發原操作。停用控制也可查看限制。
- 聚焦功能按 F1，或 Tab 到問號再 Enter；Escape 關閉並回到原功能。問號再 Tab 可到下一控制，視窗有焦點限制。
- 觸控有固定「功能說明」目錄，可搜尋名稱與內容；不依賴 hover。
- 涵蓋模型、檔案／模型庫／草稿、材料／製程、進階參數、路徑／圖層／播放、色槽／上色／高度換色及登入／送件。明示相機、預覽百分比、切片與現場列印的差異。

## 可重跑的測試

僅對隔離本機 API 執行；可指定 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`。

```bash
npm test
npm run build
BASE_URL=http://127.0.0.1:8805 node scripts/check-slicer-interactions.cjs
BASE_URL=http://127.0.0.1:8805 node scripts/check-slicer-studio.cjs
BASE_URL=http://127.0.0.1:8805 REAL_SLICE=1 node scripts/check-slicer-studio.cjs
BASE_URL=http://127.0.0.1:8805 node scripts/check-surface-paint.cjs
BASE_URL=http://127.0.0.1:8805 node scripts/check-member-workspace.cjs
BASE_URL=http://127.0.0.1:8805 node scripts/check-brand-consistency.cjs
```

`api/slicer-interaction.test.mjs` 驗證進度各狀態、百分比缺值／錯誤、全部進階說明及立即平躺後的 STL／面索引一致性。

`check-slicer-interactions.cjs` 使用真實 WebGL／幾何 worker；API 延遲與錯誤是明確本機契約測試，不宣稱模擬資料是引擎產出。逐項檢查控制均有說明並點開不同主題；測試鍵盤／觸控、18 項參數保存／無效值／重設、材料／基本設定、相機不改模型、朝向／歷史／重複執行、上傳二進位幾何、進度各階段、斷線／路徑重試、重整不重送、取消／完成競態與高度換色保護。

另以 `REAL_SLICE=1` 驗證實際 OrcaSlicer 2.4.2：三模型、鏡像、非等比縮放、gyroid／回抽取得 180 層、64,664 線段，約 42.267 分與 10.671 g。這是隔離參考機台測試，不是正式付費報價。推送 main 不等於正式站部署。
